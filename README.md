# S&L (Snake & Ladder Kingdom) by devSaenchai

A modern, responsive multiplayer Snakes & Ladders web game built with Tailwind CSS, HTML5 Canvas, Web Audio API, and Firebase Firestore for real-time online matchmaking.

## Features:
- **Game Modes:** vs AI, Local Pass & Play (2-4 players), and Online Multiplayer via Room Codes.
- **Online Lobby:** Live waiting room showing joined players with customizable colors and a host start game button.
- **Audio & Visuals:** 3D animated dice, synthesized sound effects for rolling, climbing ladders, and biting snakes.
- **Deployment Ready:** Configured for instant deployment on GitHub Pages.
